# resources/

Per-week reading and resource pages, authored as `NN_resources.qmd` (for example
`02_resources.qmd`) and linked from the "Resources" column of `schedule.qmd`.

One page per week. Keep them short: they point at readings and external links, not full content.

Note the two naming conventions, which are deliberate and different. Decks are `weekNN.qmd`
because `schedule.qmd` looks them up by that name. Resource pages are `NN_resources.qmd` so they
sort alphabetically in the editor. Neither is interchangeable with the other.
